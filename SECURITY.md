# Security

Please report security problems privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Do not open a public
issue for a vulnerability.

Include what you found, how to reproduce it and what impact you expect. You
should get a first answer within a week.

This skill contains no code, so in practice the scope is the prompt text: wording
that could make the model act outside its task or attribute words to real people.
